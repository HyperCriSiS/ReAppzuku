# Agent instructions

Read [`docs/AI_SESSION_STATE.md`](docs/AI_SESSION_STATE.md) for the current work state and [`docs/ROADMAP.md`](docs/ROADMAP.md) before planning changes. Consult [`docs/QUALITY_GATES.md`](docs/QUALITY_GATES.md) for verification requirements.

Make changes in a task branch and use a pull request to integrate into the protected `main` branch. Preserve long-lived backup branches and do not discard unmerged work.
